# Prompts

Reusable prompts for coding agents. Each prompt describes a task that the agent completes in your project.

| Prompt | Result |
| --- | --- |
| [Godot auto build](godot-auto-build/) | Build a Windows game after each push and share downloads through GitHub Releases. |

Open a prompt folder for instructions. You do not need to copy or edit workflow files.
